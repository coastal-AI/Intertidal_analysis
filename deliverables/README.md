# Deliverables

The final products of the MAREA project — what accompanies the paper.
Everything here is generated by the code in this repository; nothing is
hand-edited. Each item names the code that produced it, so any of them can
be regenerated from scratch.

## What MAREA is

*Mudflat Altimetry via Remotely-Estimated tides from the Archive.* Every
published intertidal-topography method assumes one uniform water level per
scene, taken from an ocean tide model at the mouth. Inside an estuary that
is false: the tide arrives late and deformed. MAREA measures that interior
tide from the imagery itself — every intertidal pixel is a binary
threshold sensor, and the lag that makes its wet/dry record most probable
is found by profiled Bernoulli likelihood — then corrects the elevation
inversion with it, only where the correction beats a matched null.

## Headline numbers (as of 2026-08-24)

* North coast: **130/130 cells processed**, 129 with an intertidal product;
  **108 cells adopt a measured interior tide**, 21 correctly keep the
  model's clock. 286 km² of intertidal mapped; 2.85 M pixels with
  elevation.
* Identifiability: a planted lag profile is recovered blind with
  **4.7 min** RMSE (literature-style waterline timing: 5.4).
* External validation: elevation RMSE improves or holds in every region
  tested (Tagus 0.279 → 0.247; Aveiro per-band up to +53 mm; open flats
  correctly untouched), and at the Terneuzen tide gauge — never used in
  calibration — MAREA recovers **92 %** of what any pure lag correction
  could give.
* Limits, demonstrated and kept: gain/datum are invisible to binary data
  (affine theorem); per-limb clocks are not adoptable at 465 scenes;
  censoring hides itself (recall ≈ 0.4–0.5).
