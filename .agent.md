# Agente Intertidal — Referencia rápida del paquete

Este agente te ayuda a usar eficientemente el paquete `intertidal` sin duplicar código. Consulta esta guía antes de reimplementar funcionalidades.

---

## 📦 Estructura del paquete

```
intertidal/
├── __init__.py              # Exports públicos
├── openeo_client.py         # Cliente OpenEO para Copernicus Dataspace
├── raster.py                # Lectura/escritura de GeoTIFFs (RGB, SCL)
├── scl_processor.py         # Análisis de calidad SCL, filtrado, reference maps
├── mapper.py                # Water frequency, máscaras intermareales
├── visualization.py         # Visualizaciones (RGB, SCL, reference maps)
├── tide_analyzer.py         # Análisis de datos de mareógrafos
├── tidemodel.py             # Modelos de marea (GOT4.10, FES2014, FES2022)
├── tide_metrics.py          # Métricas de calidad de distribuciones mareales
├── geometry.py              # Transformaciones geométricas
├── overpass.py              # Tiempos de paso de satélite (Overpass API)
└── notebook_compat.py       # Funciones legacy para compatibilidad
```

## 🔧 Módulos principales y funciones clave

### 1. **OpenEOClient** (`openeo_client.py`)
Cliente para descargar datos de Sentinel-2 desde Copernicus Dataspace.

#### Conectar al backend
```python
from intertidal import OpenEOClient

client = OpenEOClient()
client.connect()  # Abre navegador para login OIDC
```

#### Descargar RGB para una fecha
```python
client.download_rgb(
    date="2024-07-02",
    bbox={"west": -7.3, "south": 43.5, "east": -7.2, "north": 43.6},
    output_dir="tifs_rgb",
    polygon=aoi_polygon  # opcional: recortar a polígono
)
```

#### Descargar SCL para una fecha
```python
client.download_scl(
    date="2024-07-02",
    bbox=bbox,
    output_dir="tifs_scl",
    polygon=aoi_polygon
)
```

#### Descargar batch (múltiples fechas en paralelo)
```python
client.download_batch_rgb(
    dates=["2024-07-01", "2024-07-02", "2024-07-03"],
    bbox=bbox,
    output_dir="tifs_rgb",
    polygon=aoi_polygon,
    max_workers=3  # descarga en paralelo
)
```

#### Listar fechas disponibles
```python
available_dates = client.get_available_dates(
    bbox=bbox,
    time_extent=["2024-01-01", "2024-12-31"],
    max_cloud_cover=50  # filtro de metadatos (opcional)
)
```

#### Construir reference map (water frequency)
```python
client.build_reference_map(
    bbox=bbox,
    time_extent=["2024-01-01", "2024-12-31"],
    output_path="reference_map.tif"
)
```

**Ubicación de funciones:**
- `connect()` → línea ~48
- `download_rgb()` → línea ~80
- `download_scl()` → línea ~120
- `download_batch_rgb()` → línea ~160
- `get_available_dates()` → línea ~200
- `build_reference_map()` → línea ~250

### 3. **SCLProcessor** (`scl_processor.py`)
Procesador de análisis de calidad SCL, filtrado de fechas y reference maps.

#### Inicializar procesador
```python
from intertidal import SCLProcessor

scl_proc = SCLProcessor(bad_classes=[3, 8, 9, 10, 11])
# bad_classes: clases SCL consideradas "malas"
#   3: sombra de nube
#   8: nube probabilidad media
#   9: nube probabilidad alta
#   10: cirrus
#   11: nieve/hielo
```

#### Analizar calidad de una escena
```python
scl = RasterProcessor.read_scl("scl_2024-07-02.tif")
stats = scl_proc.compute_stats(scl)

print(f"Píxeles malos: {stats['bad_pct']:.1f}%")
print(f"Histograma: {stats['histogram']}")
```

#### Filtrar fechas por calidad global
```python
result = scl_proc.filter_dates_by_quality(
    dates=selected_dates,
    scl_dir="tifs_scl",
    max_bad_fraction=0.20  # acepta hasta 20% de píxeles malos
)

valid_dates = result["valid"]  # fechas que pasan el filtro
rejected_dates = result["rejected"]  # fechas descartadas
stats_dict = result["stats"]  # diccionario {fecha: stats}
```

#### Cargar stack de SCLs
```python
stack = scl_proc.load_stack(
    dates=clean_dates,
    scl_dir="tifs_scl"
)
# Retorna: (n_dates, H, W) uint8
```

#### Construir reference map local
```python
ref_map, p_water, p_land = scl_proc.build_reference_map_local(
    scl_stack=stack,
    water_threshold=0.70,  # P(agua) > 0.70 → agua estable
    land_threshold=0.70,   # P(tierra) > 0.70 → tierra estable
    buffer_px=5            # buffer espacial alrededor de transición
)
# ref_map: (H, W) uint8 con valores 0, 1, 2
# p_water: (H, W) float32 con probabilidad de agua
# p_land: (H, W) float32 con probabilidad de tierra
```

#### Filtrar fechas usando zona de transición
```python
result_transition = scl_proc.filter_dates_with_transition_mask(
    dates=selected_dates,
    scl_dir="tifs_scl",
    transition_mask=transition_mask,  # (H, W) bool: True = intermareal
    max_bad_fraction=0.20
)

valid_dates = result_transition["valid"]
rejected_dates = result_transition["rejected"]
stats_dict = result_transition["stats"]
```

#### Analizar nubosidad en zona de transición
```python
stats_transition = scl_proc.compute_transition_cloud_stats(
    scl_array=scl,
    transition_mask=transition_mask,
    bad_classes=[3, 8, 9, 10, 11]
)

print(f"Píxeles malos en transición: {stats_transition['bad_pct']:.1f}%")
print(f"Total píxeles en transición: {stats_transition['total_transition_px']}")
```

**Ubicación de funciones:**
- `__init__()` → línea ~114
- `compute_stats()` → línea ~143
- `filter_dates_by_quality()` → línea ~190
- `load_stack()` → línea ~250
- `build_reference_map_local()` → línea ~300
- `filter_dates_with_transition_mask()` → línea ~400
- `compute_transition_cloud_stats()` → línea ~460

## � Detección de marismas (vegetación inundada)

### Problema

En zonas de marisma, la vegetación halófita (Spartina, Salicornia) puede estar sumergida pero el SCL la clasifica como "vegetación" (clase 4) en lugar de agua. Esto causa:
- Water frequency subestimado
- Reference map incorrecto
- Waterlines desplazadas → batimetría errónea

### Solución: NDWI/MNDWI

Usar índices espectrales para detectar agua bajo vegetación:

```python
# NDWI = (Green - NIR) / (Green + NIR)
# MNDWI = (Green - SWIR1) / (Green + SWIR1)  ← más sensible a marismas

# Funciones disponibles (ver notebook):
ndwi, mndwi = compute_ndwi_mndwi_openeo(conn, date, bbox, polygon)

flooded_veg = detect_flooded_vegetation(
    scl=scl,
    ndwi=ndwi,
    mndwi=mndwi,
    mndwi_threshold=0.3,  # MNDWI > 0.3 indica vegetación inundada
    use_mndwi=True
)

scl_corrected = correct_scl_for_marshes(scl, flooded_veg)
# → Reclasifica vegetación inundada como agua (clase 6)
```

### Integración en pipeline

```python
# Opción 1: Corregir SCL antes de water frequency
for date in valid_dates:
    ndwi, mndwi = compute_ndwi_mndwi_openeo(conn, date, bbox, polygon)
    scl = load_scl(date)
    flooded_veg = detect_flooded_vegetation(scl, ndwi, mndwi)
    scl_corrected = correct_scl_for_marshes(scl, flooded_veg)
    # Usar scl_corrected para calcular water frequency

# Opción 2: Ajustar waterlines en zonas de marisma
# (si ya tienes waterlines calculadas)
mndwi_mean = compute_mean_mndwi(valid_dates)
marsh_mask = (mndwi_mean > 0.3) & (scl_mode == 4)
# Expandir waterlines en marsh_mask
```

**Referencias:**
- McFeeters (1996): NDWI
- Xu (2006): MNDWI para suprimir vegetación
- Adam et al. (2010): Vegetación de humedales

## �🎯 Patrones comunes de uso

### Pattern 1: Pipeline completo de descarga y filtrado

```python
from intertidal import OpenEOClient, SCLProcessor, RasterProcessor

# 1. Conectar y listar fechas
client = OpenEOClient()
client.connect()

available_dates = client.get_available_dates(
    bbox=bbox,
    time_extent=["2024-01-01", "2024-12-31"]
)

# 2. Descargar batch de fechas
client.download_batch_scl(available_dates, bbox, "tifs_scl", max_workers=5)
client.download_batch_rgb(available_dates, bbox, "tifs_rgb", max_workers=5)

# 3. Filtrar por calidad global
scl_proc = SCLProcessor(bad_classes=[3, 8, 9, 10, 11])
result = scl_proc.filter_dates_by_quality(
    available_dates, "tifs_scl", max_bad_fraction=0.20
)

clean_dates = result["valid"]
```

### Pattern 2: Construcción de reference map y filtrado en transición

```python
# 1. Cargar stack de fechas limpias
stack = scl_proc.load_stack(clean_dates, "tifs_scl")

# 2. Construir reference map
ref_map, p_water, p_land = scl_proc.build_reference_map_local(
    stack,
    water_threshold=0.70,
    land_threshold=0.70,
    buffer_px=5
)

# 3. Extraer máscara de transición
transition_mask = (ref_map == 0)

# 4. Filtrar fechas usando zona de transición
result_transition = scl_proc.filter_dates_with_transition_mask(
    selected_dates,
    "tifs_scl",
    transition_mask,
    max_bad_fraction=0.20
)

final_dates = result_transition["valid"]
```

### Pattern 3: Visualización diagnóstica

```python
from intertidal import Visualizer

# Visualizar diagnóstico de una fecha
test_date = "2024-07-02"
scl = RasterProcessor.read_scl(f"tifs_scl/scl_{test_date}.tif")

Visualizer.plot_diagnostic_panel(
    scl_original=scl,
    reference_map=ref_map,
    transition_mask=transition_mask,
    date=test_date,
    bad_classes=[3, 8, 9, 10, 11],
    figsize=(22, 6)
)
```

### Pattern 4: Análisis de marea para waterline

```python
from intertidal import PyTMDTideModel
from intertidal.tide_metrics import (
    calcular_cobertura_rango_mareal,
    calcular_uniformidad_ks
)

# 1. Calcular alturas de marea para las fechas
tide_model = PyTMDTideModel("GOT4.10", "./tide_models")

tide_heights = []

# 2. Evaluar cobertura mareal
cobertura = calcular_cobertura_rango_mareal(
    valores_validos=tide_heights,
    valores_totales=tide_heights_all_year
)

# 3. Evaluar uniformidad
uniformidad = calcular_uniformidad_ks(tide_heights)

print(f"Cobertura: {cobertura['cobertura_pct']:.1f}%")
print(f"Uniformidad (KS): {uniformidad['ks_statistic']:.3f}")
```

## ⚠️ Errores comunes a evitar

### 1. No validar TIFFs antes de leer
```python
# ❌ MAL
scl = RasterProcessor.read_scl(path)

# ✅ BIEN
if RasterProcessor.is_valid_tif(path):
    scl = RasterProcessor.read_scl(path)
else:
    print(f"⚠️ {path} está vacío o corrupto")
```

### 2. Confundir filtro global vs filtro en transición
```python
# Filtro GLOBAL: evalúa toda el AOI
result_global = scl_proc.filter_dates_by_quality(
    dates, "tifs_scl", max_bad_fraction=0.20
)

# Filtro EN TRANSICIÓN: evalúa solo la zona intermareal
result_transition = scl_proc.filter_dates_with_transition_mask(
    dates, "tifs_scl", transition_mask, max_bad_fraction=0.20
)

# El filtro en transición es más permisivo y conserva más fechas
```

### 3. No normalizar RGB para visualización
```python
# ❌ MAL (valores crudos, sin contraste)
rgb = RasterProcessor.read_rgb(path, normalize=False)

# ✅ BIEN (normalizado por percentiles 2%-98%)
rgb = RasterProcessor.read_rgb(path, normalize=True)
plt.imshow(rgb)
```

### 4. Olvidar buffer espacial en reference map
```python
# ❌ MAL (transición muy estrecha, puede perder píxeles)
ref_map, _, _ = scl_proc.build_reference_map_local(
    stack, buffer_px=0
)

# ✅ BIEN (buffer de 5 px asegura zona de transición realista)
ref_map, _, _ = scl_proc.build_reference_map_local(
    stack, buffer_px=5
)
```

### 5. No considerar vegetación inundada (marismas)
```python
# ❌ MAL (ignora marismas, water frequency subestimado)
water_freq = compute_water_frequency(dates)

# ✅ BIEN (corrige SCL en zonas de marisma)
for date in dates:
    ndwi, mndwi = compute_ndwi_mndwi_openeo(conn, date, bbox, polygon)
    scl = load_scl(date)
    flooded_veg = detect_flooded_vegetation(scl, ndwi, mndwi, mndwi_threshold=0.3)
    scl_corrected = correct_scl_for_marshes(scl, flooded_veg)
    # Usar scl_corrected para water frequency
```

## 🔍 Debugging: Clases SCL y su significado

Cuando debuggees problemas de clasificación SCL, recuerda:

```python
SCL_CLASSES = {
    0:  "Sin datos",
    1:  "Saturado/Defectuoso",
    2:  "Sombra oscura",
    3:  "Sombra de nube",        # ← MALO
    4:  "Vegetación",             # ← BUENO
    5:  "No vegetación/suelo",    # ← BUENO
    6:  "Agua",                   # ← BUENO
    7:  "Incierto",
    8:  "Nube media",             # ← MALO
    9:  "Nube alta",              # ← MALO
    10: "Cirrus",                 # ← MALO
    11: "Nieve/Hielo",            # ← MALO
}
```

**Píxeles "malos" por defecto:** `[3, 8, 9, 10, 11]`

**Píxeles "buenos" (observaciones claras):** `[4, 5, 6]`
