# poster/

The poster presented at **CARTOGRASS 2026**, Simposio Ibérico de Cartografía y
Seguimiento de Praderas Marinas, Cartagena, 24–26 November 2026.

**MAREA: a method for mapping intertidal topography using Sentinel-2 openEO data cubes.**
Jorge Alías Álvarez¹, Fernando García-González², Pablo González¹.
¹ University of Oviedo, Spain · ² Instituto Español de Oceanografía (IEO-CSIC), Spain.

* Format: A0 portrait, 841 × 1189 mm.
* PDF: not public yet.

The maps on the poster can be explored on the website, and the method is run in the
notebooks of this repository: see the [main README](../README.md).
