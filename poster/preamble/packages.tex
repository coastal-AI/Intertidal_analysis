% Fira Sans: a humanist grotesque with real character at display size, and
% verified complete here — Type1, TFM and map all present, and it embeds and
% subsets cleanly. Inter was the first choice but its MiKTeX package is
% incomplete on this machine (missing NFSS font descriptors, and its `lining'
% option references a \newif the package never declares); TeX Gyre Heros also
% works but is a Helvetica clone with nothing to say. `book' is Fira's regular
% weight, which holds up better than Light across a 1 m sheet.
\usepackage[sfdefault,book]{FiraSans}
% Without a scalable typewriter, \texttt falls back to EC, which METAFONT
% renders as a Type 3 BITMAP — visibly jagged blown up to a metre, and
% something print shops reject. Fira Mono is Type 1 and matches the text face.
\usepackage[scaled=0.92]{FiraMono}
\usepackage{microtype}
